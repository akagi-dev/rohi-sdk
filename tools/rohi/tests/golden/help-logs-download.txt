Save every retained log file of the active storage of the device.

The files are the compressed segments as the device keeps them
(`rohi1.log.lz4`, ...; `.log` for plain segments), oldest first, and are
written unchanged: `lz4 -d rohi1.log.lz4` shows the text. Records logged
while the download runs are not part of it. A file that already exists is
not replaced unless --force is given.

Usage: rohi logs download [OPTIONS]

Options:
  -d, --directory <DIR>
          The directory to write the files to; it is created when missing
          
          [default: .]

      --force
          Replace files that already exist

  -h, --help
          Print help (see a summary with '-h')

Target:
  -D, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

      --color <WHEN>
          Color the text output

          Possible values:
          - auto:   Color when stdout is a terminal, unless `NO_COLOR` is set or `TERM` is `dumb`
          - always: Always color
          - never:  Never color
          
          [default: auto]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device, or to connect to a TCP endpoint
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Examples:
  rohi logs download
  rohi logs download -d ./logs
  rohi logs download --force

Cryptographic identity of the device: show, provision or erase.

Without a command: show the identity state and the public key as a Robonomics address.

Usage: rohi identity [OPTIONS] [COMMAND]

Commands:
  provision  Derive the identity of this device from a master seed and install it
  erase      Remove the identity; the device must be provisioned again to sign
  help       Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Examples:
  rohi identity
  rohi identity provision --number 42 --seed master.suri
  rohi identity erase --yes

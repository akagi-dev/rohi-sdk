Export or restore device configuration.

Backups contain persistent device settings that can be restored later or applied to another compatible ROHI device.

Secrets that cannot be read back from the device are not included. They may be requested during restore.

Usage: rohi backup [OPTIONS] <COMMAND>

Commands:
  export  Export device configuration
  import  Validate and restore device configuration
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Examples:
  rohi backup export backup.json
  rohi backup export > backup.json
  rohi backup import backup.json --dry-run
  rohi backup import backup.json

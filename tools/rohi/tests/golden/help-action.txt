List and run the actions of the services.

Actions are explicit operations a service offers, for example scanning for networks or reconnecting. The device describes the arguments and the results of every action.

Usage: rohi action [OPTIONS] <COMMAND>

Commands:
  list      List the actions of all services
  describe  Describe the arguments and results of an action
  run       Run an action
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

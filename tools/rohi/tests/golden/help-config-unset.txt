Unset optional fields of a section.

Unset is not the same as an empty string or zero: the field has no value afterwards.

Usage: rohi config unset [OPTIONS] <SECTION> <FIELDS>...

Arguments:
  <SECTION>
          The section

  <FIELDS>...
          The fields to unset

Options:
      --dry-run
          Validate on the device without storing anything

  -h, --help
          Print help (see a summary with '-h')

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

      --color <WHEN>
          Color the text output

          Possible values:
          - auto:   Color when stdout is a terminal, unless `NO_COLOR` is set or `TERM` is `dumb`
          - always: Always color
          - never:  Never color
          
          [default: auto]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Examples:
  rohi config unset network password

Show the firmware and the build of the device.

The build identifier is `<platform>/<version>+<sha8>.<YYYYMMDD>`: the platform, the firmware version, the first eight characters of the Git commit and the UTC build date. The device sends the same text as the `User-Agent` of its telemetry requests.

Usage: rohi info [OPTIONS]

Options:
  -h, --help
          Print help (see a summary with '-h')

Target:
  -D, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

      --color <WHEN>
          Color the text output

          Possible values:
          - auto:   Color when stdout is a terminal, unless `NO_COLOR` is set or `TERM` is `dumb`
          - always: Always color
          - never:  Never color
          
          [default: auto]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device, or to connect to a TCP endpoint
          
          [default: 10]

      --psk-file <FILE>
          File with the pre-shared key of a TCP endpoint (64 hex characters). With it `rohi` completes the handshake and encrypts every request: the way to change or provision a `protected` endpoint, and the only way into a `private` one. Without it requests are plaintext, which a `protected` endpoint answers for reads only. Never put the key itself on the command line
          
          [env: ROHI_PSK_FILE=]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Examples:
  rohi info
  rohi -o json info

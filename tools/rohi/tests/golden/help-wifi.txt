Inspect and configure Wi-Fi.

Without a command: show the Wi-Fi status.

Usage: rohi wifi [OPTIONS] [COMMAND]

Commands:
  status      Show the Wi-Fi status (default)
  scan        List networks the device sees
  connect     Join a network and wait until the device is connected
  configure   Change the Wi-Fi configuration; omitted settings are kept
  reconnect   Reconnect now
  disconnect  Disconnect and stay idle
  forget      Remove the stored Wi-Fi configuration
  help        Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Examples:
  rohi wifi
  rohi wifi scan
  rohi wifi connect office

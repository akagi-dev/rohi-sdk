║      Robonomics Open Hardware terminal Interface     ║
║                                                      ║

Control Robonomics devices from terminal.

CLI discovers nearby ROHI devices, shows the status of their services,
manages their configuration and runs their actions. Sections, services
and actions are discovered from the device, so new firmware modules
need no update of this tool.

Usage: rohi [OPTIONS] <COMMAND>

Commands:
  scan    Discover nearby ROHI devices
  status  Show the runtime status of the device and its services
  config  Read and change the persistent configuration.
  action  List and run the actions of the services.
  logs    Show, follow, download or clear the device log
  admin   Manage the administrator key of signed requests
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Target:
  -D, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

      --color <WHEN>
          Color the text output

          Possible values:
          - auto:   Color when stdout is a terminal, unless `NO_COLOR` is set or `TERM` is `dumb`
          - always: Always color
          - never:  Never color
          
          [default: auto]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device, or to connect to a TCP endpoint
          
          [default: 10]

      --admin-key <FILE>
          File with the administrator key (64 hex characters). A restricted TCP endpoint of a device wants a signature of it on every change; with the key `rohi` signs automatically. Never put the key itself on the command line; create the file with `rohi admin keygen FILE`
          
          [env: ROHI_ADMIN_KEY=]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Run `rohi <COMMAND> --help` for more information about a command.
Any other word is a service of the device: `rohi SERVICE ACTION [ARG]...` runs one
of its actions and `rohi SERVICE` lists them, see `rohi action --help`.

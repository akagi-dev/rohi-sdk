Control Robonomics devices from terminal.

CLI discovers nearby ROHI devices, shows the status of their services,
manages their configuration and runs their actions. Sections, services
and actions are discovered from the device, so new firmware modules
need no update of this tool.

Usage: rohi [OPTIONS] <COMMAND>

Commands:
  scan    Discover nearby ROHI devices
  status  Show the runtime status of the device and its services
  config  Read and change the persistent configuration
  action  List and run the actions of the services
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Run `rohi <COMMAND> --help` for more information about a command.

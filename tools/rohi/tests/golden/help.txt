Control Robonomics devices from terminal.

CLI discovers nearby ROHI devices, reads their status and sensors,
manages device configuration, and provides backup/restore workflows.

Usage: rohi [OPTIONS] <COMMAND>

Commands:
  scan      Discover nearby ROHI devices
  status    Show device information, capabilities, and current status
  sensors   Read current sensor measurements
  config    Inspect device configuration
  wifi      Inspect and configure Wi-Fi
  time      Show the wall-clock time of the device and its synchronization state
  backup    Export or restore device configuration
  identity  Cryptographic identity of the device: show, provision or erase [alias: id]
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Run `rohi <COMMAND> --help` for more information about a command.

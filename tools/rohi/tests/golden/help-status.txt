Show device information, capabilities, and current status.

Displays the connection, firmware and board information, supported capabilities, and available runtime status such as Wi-Fi connectivity, the wall-clock time and identity. Sections the device does not support are omitted.

Usage: rohi status [OPTIONS]

Options:
  -h, --help
          Print help (see a summary with '-h')

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Examples:
  rohi status
  rohi -d A12F status
  rohi -d A12F -o json status

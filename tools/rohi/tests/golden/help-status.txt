Show the runtime status of the device and its services.

Without a service this is one compact request: the device health set by the firmware and the state, health and readiness of every service. With a service name it shows that service in detail: its service-specific values and the active issues, each with a stable code. Services are discovered from the device; `rohi status` lists them.

Status is what is happening now. What the device is set up to do is `rohi config`.

Usage: rohi status [OPTIONS] [SERVICE]

Arguments:
  [SERVICE]
          The service to show in detail

Options:
  -w, --watch
          Poll the device and print again whenever something changed, until interrupted. On a terminal the screen is refreshed in place instead

      --interval <SECONDS>
          Pause between polls of --watch
          
          [default: 2]

  -h, --help
          Print help (see a summary with '-h')

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

      --color <WHEN>
          Color the text output

          Possible values:
          - auto:   Color when stdout is a terminal, unless `NO_COLOR` is set or `TERM` is `dumb`
          - always: Always color
          - never:  Never color
          
          [default: auto]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Examples:
  rohi status
  rohi status wifi
  rohi status --watch
  rohi status connectivity --watch --interval 5
  rohi -o json status sensors

Format the configuration storage of the device.

Wipes the whole configuration partition of the device: every section, the device identity (the device becomes unprovisioned) and anything else stored there, including the section versions and the damaged storage of a corrupted device, which is repaired this way. The runtime returns to the defaults. A confirmation prompt is shown unless --yes is passed.

To restore the defaults of a single section use `rohi config reset`.

Usage: rohi factory-reset [OPTIONS]

Options:
  -y, --yes
          Skip the confirmation prompt

  -h, --help
          Print help (see a summary with '-h')

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

      --color <WHEN>
          Color the text output

          Possible values:
          - auto:   Color when stdout is a terminal, unless `NO_COLOR` is set or `TERM` is `dumb`
          - always: Always color
          - never:  Never color
          
          [default: auto]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Examples:
  rohi factory-reset
  rohi factory-reset --yes

Remove the log history of the active storage

Usage: rohi logs clear [OPTIONS]

Options:
  -y, --yes
          Do not ask for confirmation

  -h, --help
          Print help (see a summary with '-h')

Target:
  -D, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

      --color <WHEN>
          Color the text output

          Possible values:
          - auto:   Color when stdout is a terminal, unless `NO_COLOR` is set or `TERM` is `dumb`
          - always: Always color
          - never:  Never color
          
          [default: auto]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device, or to connect to a TCP endpoint
          
          [default: 10]

      --psk-file <FILE>
          File with the pre-shared key of a TCP endpoint (64 hex characters). A restricted endpoint serves only clients that complete a handshake with it, and `rohi` then encrypts every request. Never put the key itself on the command line; get a key from the device with `rohi control_tcp reveal_psk`, which prints it
          
          [env: ROHI_PSK_FILE=]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Examples:
  rohi logs clear
  rohi logs clear --yes

Export device configuration.

Writes a versioned JSON backup of the stored configuration to FILE, or to stdout without FILE. Runtime state and secrets the device does not reveal, such as the Wi-Fi password, are not included; the backup only records that a password is required.

Usage: rohi backup export [OPTIONS] [FILE]

Arguments:
  [FILE]
          File to write; stdout when omitted

Options:
  -h, --help
          Print help (see a summary with '-h')

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Examples:
  rohi backup export backup.json
  rohi backup export > backup.json

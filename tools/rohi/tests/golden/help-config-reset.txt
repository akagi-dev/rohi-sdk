Remove the stored section and restore its defaults.

A confirmation prompt is shown unless --yes is passed.

Usage: rohi config reset [OPTIONS] <SECTION>

Arguments:
  <SECTION>
          The section

Options:
  -y, --yes
          Skip the confirmation prompt

      --dry-run
          Validate on the device without removing anything

  -h, --help
          Print help (see a summary with '-h')

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

Examples:
  rohi config reset connectivity
  rohi config reset connectivity --yes

Read and change the persistent configuration.

The device lists its configuration sections and describes their fields; values are parsed and checked against that description. Changes are patches applied atomically per section: if anything is invalid, nothing is stored. Secrets are write-only and are never shown or exported.

Usage: rohi config [OPTIONS] <COMMAND>

Commands:
  list           List the configuration sections of the device
  describe       Describe the fields of a section
  get            Show the values of a section, or of one field
  set            Set fields of a section: `FIELD=VALUE` pairs, stored atomically
  unset          Unset optional fields of a section
  reset          Remove the stored section and restore its defaults
  factory-reset  Remove every stored section and restore all defaults
  export         Write the configuration of the device to a JSON file
  diff           Show what applying a configuration file would change
  apply          Apply a configuration file
  help           Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

Target:
  -d, --device <DEVICE>
          Target device: advertised name, ID, or a unique prefix or suffix of either; or a URI such as ble://NAME or tcp://HOST:PORT. Without it the only device found is used, or you choose among several
          
          [env: ROHI_DEVICE=]

Output:
  -o, --output <FORMAT>
          Output format

          Possible values:
          - human: Text for people
          - json:  JSON with a stable, versioned schema, for scripts
          
          [default: human]

      --color <WHEN>
          Color the text output

          Possible values:
          - auto:   Color when stdout is a terminal, unless `NO_COLOR` is set or `TERM` is `dumb`
          - always: Always color
          - never:  Never color
          
          [default: auto]

Connection:
      --scan-timeout <SECONDS>
          How long to search for the target device
          
          [default: 10]

      --timeout <SECONDS>
          How long to wait for a device response
          
          [default: 10]

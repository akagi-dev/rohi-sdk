# Device identity

Every provisioned ROHI device has exactly one Ed25519 identity. It is **provisioned from the host, never generated by
the device**, and is the cryptographic identity used to sign telemetry. The master seed and the provisioning number
exist only on the provisioning host: `rohi` derives a per-device secret with the hard junction `//<number>` and sends
only that secret over the control protocol. The device stores the secret in the normal [configuration store](config.md),
so it inherits transactional writes and power-loss recovery; the public key is derived and never persisted.

`rohi-identity` is `no_std` and has no transport dependency. It provides the zeroizing `Secret`, the `Identity`
configuration section, `PublicKey` and `Signature`, and the `Signer` abstraction. A signer signs exactly the bytes it
is given; message formats and replay protection belong to the telemetry protocol ([Telemetry](connectivity.md)), which
signs every frame with the identity. The `identity` [service](service.md) exposes the status and the `provision` and
`erase` actions through the [control protocol](control.md); there is no dedicated `rohi` command, the generic
`rohi status identity` and `rohi action identity ...` are used ([Actions](../use/desktop/actions.md)). A device
without an identity keeps working and only operations that need it fail with `IdentityError::NotProvisioned`.

| Item | Role |
|------|------|
| `Identity` | the persisted section; holds only the 32-byte secret |
| `Signer`, `IdentitySigner` | sign exact bytes; the private key cannot be read back |
| `PublicKey`, `Signature` | 32 / 64 raw bytes; verification |
| `IdentityService`, `IdentityStore` | the `identity` service and the persistence the firmware implements |

Status: implemented and host-tested, **not verified on hardware** ([support matrix](../support/matrix.md), checklist in
[Hardware testing](../validation/hardware-testing.md)). **Security caveat:** BLE pairing is not implemented, and the
Altruist Urban firmware runs `OpenPolicy`, so today anyone in radio range can provision or erase an identity; provision
devices in a trusted place. The stored section is [persistent ABI](../reference/persistent-abi.md).
